Centralne miejsce do zarządzania linkami

Dodawaj grupy, podgrupy, linki poza grupami, zmieniaj kolejność, eksportuj dane do JSON i odświeżaj zawartość z pliku. Ta wersja jest przygotowana pod GitHub Pages i dopracowana dla desktopu oraz smartfonów.

Ładowanie danych...

Na smartfonie menu otwiera się jako czytelny panel od dołu. Wyszukiwarka filtruje grupy, podgrupy i linki. Dane możesz edytować lokalnie, a potem wyeksportować do pliku JSON do GitHub Pages.
Wskazówka produkcyjna: trzymaj plik index.html oraz data.json w tym samym katalogu repozytorium GitHub Pages. W ustawieniach JSON ustaw ścieżkę ./data.json.
